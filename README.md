## 📝 Overview

The **Super Store Sales Dashboard** is an interactive data visualization project designed to analyze and monitor sales performance. It provides insights into sales trends, profit, customer segments, shipping modes, and category-wise performance using visual charts and graphs.

This dashboard helps businesses make data-driven decisions by presenting complex data in an easy-to-understand visual format.

---

## 🚀 Features

* 📈 **Sales by Category & Sub-Category** – Compare performance across Furniture, Technology, and Office Supplies.
* 💰 **Profit Analysis** – Track profit trends monthly and yearly.
* 📊 **Sales by Month and Year** – Visualize sales growth and seasonal patterns.
* 👥 **Customer Segmentation** – Analyze sales distribution across Consumer, Corporate, and Home Office segments.
* 🚚 **Sales by Ship Mode** – Compare shipping methods like Standard Class, Second Class, First Class, and Same Day.
* 📉 **Time Series Sales Analysis** – Monitor sales trends by order date.
